# Morph Menu

## Purpose

`MorphMenu` expands a compact trigger into one spatially continuous navigation surface. It suits mobile headers, editorial menus and intentionally sparse portfolio navigation.

Use one trigger and a short, clear destination list. Avoid it when links should remain permanently visible, when a native disclosure is sufficient, or when opening it would compete with another modal. Do not replace the morph with an unrelated fading panel.

Preserve semantic links, Escape, focus trapping/restoration and body-scroll behaviour supplied by `Morph`. Reduced motion opens immediately and mobile keeps the same reading order. Keep heavy media and continuous effects out of the expanded surface.
