# Workflow Motion

## Purpose
Motion should clarify state, continuity, and destination in product workflows.

## Guidance
Use transforms/opacity, preserve object identity, keep stacks capped, clean timers/listeners, and let native semantics carry meaning.

## Accessibility and anti-patterns
Honor reduced motion and avoid bounce, stagger-on-every-keystroke, per-frame React state, or decorative motion that competes with the task.
