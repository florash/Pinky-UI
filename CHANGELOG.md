# Changelog

## 0.1.0 — Release candidate

Initial public release candidate for Pinky UI.

- Interaction-first React primitives, components, layouts, effects, experiences and product systems.
- 284 public Skill routes backed by 283 canonical Markdown recipes and one intentional legacy alias.
- Direct live previews across the website catalogue, with responsive, keyboard and reduced-motion paths.
- Seven scoped `@pinky-ui/*` packages with aligned `0.1.0` versions and publishable package boundaries.
- Documentation, package metadata, sitemap, robots output and deterministic release verification.

Packages are not published to npm by this repository checkpoint.
